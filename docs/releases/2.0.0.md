age-tool 2.0 adds a **desktop app for Linux**, so anyone can encrypt and decrypt files without a terminal. Keys now live in a per-user **key store** instead of the current folder.

## What's new

- **Desktop app for Linux.** Create a key, encrypt and decrypt files, share your public key and add contacts, all without a terminal. On first start it offers to add itself to your desktop:
  - age-tool appears in your app menu
  - double-clicking a `.age` file decrypts it
  - right-click **Encrypt** / **Decrypt** entries are added to Files (GNOME, under **Scripts**), Dolphin (KDE), Nemo (Cinnamon) and Thunar (XFCE)
- **Key store.** Keys live in one folder per user, so the command-line tool works from any folder. Keys from 1.x are offered for import the first time you run it in their folder, and your original files are never changed. `--keys .` keeps the 1.x behaviour.
- **Contacts.** Import someone else's public key to encrypt files for them, and export or share your own. A private key pasted by mistake is refused.
- **Central activity log**, kept alongside the 1.x-style log next to each file. The desktop app's **View activity** shows it.
- **Checksums.** `SHA256SUMS` lists the hash of every file in the release.

The desktop app and the command-line tool share the same core code, so both enforce the same rules: passphrase-protected private keys only, 12-character minimum passphrases, 3 attempts, owner-only file permissions, and atomic output that never leaves partial plaintext behind.

**Upgrading from 1.x?** Read [Upgrading to 2.0](https://github.com/anveitch/age-tool/blob/v2.0.0/docs/upgrading-to-2.0.md) first. Files encrypted with 1.x open in 2.0, and the other way round.

## Downloads

| You have | Download |
|---|---|
| Linux PC or laptop (desktop app) | `age-tool-linux-x64.AppImage` |
| Linux on ARM, e.g. Raspberry Pi (desktop app) | `age-tool-linux-arm64.AppImage` |
| macOS, Apple Silicon (command line) | `age-tool-macos-arm64` |
| macOS, Intel (command line) | `age-tool-macos-intel` |
| Linux (command line) | `age-tool-linux-x64` or `age-tool-linux-arm64` |
| Windows (command line) | `age-tool-windows-x64.exe` |

**Desktop app:** download the AppImage, make it executable (in Files, right-click → **Properties** → **Executable as Program**), then double-click it. Nothing else needs installing. It needs Ubuntu 22.04 or newer, or a similar distribution (Debian 12, Linux Mint 21, Fedora 36 and later). The [user guide](https://github.com/anveitch/age-tool/blob/v2.0.0/docs/user-guide.md) covers the rest.

**Homebrew (macOS command line):**

    brew update
    brew upgrade age-tool

**Check your download** (optional): put `SHA256SUMS` in the same folder and run `sha256sum -c SHA256SUMS --ignore-missing` (Linux) or `shasum -a 256 -c SHA256SUMS --ignore-missing` (macOS). Your file should say `OK`.

## Notes

- The desktop app is Linux only for now. macOS and Windows have the command-line tool.
- The menus and right-click entries have been tested on GNOME (Ubuntu) and XFCE. The KDE (Dolphin) and Cinnamon (Nemo) entries are included but haven't been tested yet, so please report any problems with them.

## Reporting problems

[Open an issue](https://github.com/anveitch/age-tool/issues) with your Linux distribution and desktop (e.g. Ubuntu 24.04, GNOME), and what you did, what you expected, and what happened. Never include your passphrase or a private key (`AGE-SECRET-KEY…`) in a report.
