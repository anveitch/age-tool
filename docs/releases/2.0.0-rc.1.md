**Test release.** This is a release candidate for age-tool 2.0, for testers. Please report anything that goes wrong or is confusing; see the end of these notes.

## What's new in 2.0

- **Desktop app for Linux.** Encrypt and decrypt files, create keys and share your public key without a terminal. On first start it offers to add itself to your desktop:
  - age-tool appears in your app menu
  - double-clicking a `.age` file decrypts it
  - right-click **Encrypt** / **Decrypt** entries are added to Files, Dolphin, Nemo and Thunar
- **Key store.** Keys now live in one folder per user, so the command-line tool works from any folder. Keys from 1.x are offered for import the first time you run it in their folder, and your original files are never changed. `--keys .` keeps the 1.x behaviour.
- **Contacts.** Import someone else's public key to encrypt files for them, and export or share your own.
- **Central activity log**, kept alongside the 1.x-style log next to each file.
- **Checksums.** `SHA256SUMS` lists the hash of every file in the release.

1.x users: read [Upgrading to 2.0](https://github.com/anveitch/age-tool/blob/v2.0.0-rc.1/docs/upgrading-to-2.0.md) first.

## Downloads

| You have | Download |
|---|---|
| Linux PC or laptop (desktop app) | `age-tool-linux-x64.AppImage` |
| Linux on ARM, e.g. Raspberry Pi (desktop app) | `age-tool-linux-arm64.AppImage` |
| Command-line tool | `age-tool-macos-arm64`, `age-tool-macos-intel`, `age-tool-linux-x64`, `age-tool-linux-arm64` or `age-tool-windows-x64.exe` |

The desktop app needs Ubuntu 22.04 or newer, or a similar distribution (Debian 12, Linux Mint 21, Fedora 36 and later).

**Desktop app:** download the AppImage, make it executable (in Files, right-click → **Properties** → **Executable as Program**), then double-click it. The [user guide](https://github.com/anveitch/age-tool/blob/v2.0.0-rc.1/docs/user-guide.md) covers the rest.

**Check your download** (optional): put `SHA256SUMS` in the same folder and run `sha256sum -c SHA256SUMS --ignore-missing` (Linux) or `shasum -a 256 -c SHA256SUMS --ignore-missing` (macOS). Your file should say `OK`.

Homebrew stays on 1.2.2 until 2.0.0 is released.

## Known limitations in this test release

- The desktop app has been tested in containers, but not yet on a real PC or on every desktop. Menus, right-click entries and the app's icon in the dock or taskbar may not work everywhere yet.
- The desktop app is Linux only. macOS and Windows have the command-line tool.

## Please report

[Open an issue](https://github.com/anveitch/age-tool/issues) and include:

- your Linux distribution and desktop (e.g. Ubuntu 24.04, GNOME)
- what you did, what you expected, and what happened

Never include your passphrase or a private key (`AGE-SECRET-KEY…`) in a report. Public keys (`age1…`) are fine to include.
